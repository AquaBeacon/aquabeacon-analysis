グラフを編集

スライダーで見た目を調整し、図の端をドラッグして縦横の大きさを変えられます。

フォント・文字サイズこのPCのフォントを選べます。全体サイズを基準に、個別指定したサイズを優先します。空欄は元のサイズを保ちます。
以下は選択中のグラフの個別サイズです。
表示範囲（xlim / ylim）
図の大きさ・全体設定
軸ラベル・目盛り・凡例対数軸は正の表示範囲を先に指定してください。主・補助目盛り間隔は線形軸用です。指定目盛り位置と文字は対応する個数を入力します。パネル位置を変更すると自動配置を解除します。
系列・注釈点サイズは散布図では面積 pt²、折れ線の点では直径 pt。空欄は元の設定を保ちます。

青いハンドルで幅・高さを変更。離すと配置を再計算します。数値入力・矢印キーでも調整できます。プレビューは元の縦横比を維持します。
PNGSVGPDF

保存ボタンで .style.json と .edited.png / .svg / .pdf を元の図と同じフォルダに保存します。終了時は「保存して終了」または端末で Ctrl+C。
