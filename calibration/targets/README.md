# 40 mm カメラ校正用チェッカーボード

X1-Carbon + AMSで黒・白のPLAを使う5列×6行のチェッカーボード。1マス40 mm、外形200×240×2.2 mm。内部交点は4×5個。表面は黒白とも同じ高さ。

## ファイル

- `checkerboard_40mm.scad`: 寸法と層数を編集する原本。`part`を`black`/`white`にして各STLを書き出す。
- `checkerboard_40mm.3mf`: 黒と白を1つの組立モデルにした印刷用データ。
- `checkerboard_40mm_black.stl` / `checkerboard_40mm_white.stl`: 色ごとの部品。両方を同時にBambu Studioへ読み込み、単一オブジェクトの部品として扱う。
- `make_3mf.py`: STLから3MFを再生成するスクリプト（`trimesh`が必要）。

## 印刷

1. Bambu Studioで3MFを開き、黒部品に黒PLA、白部品に白PLAを割り当てる。配置を動かさず、白が黒いベースの上にあることを確認する。
2. 0.4 mmノズル、0.20 mm層高にする。黒ベース9層（1.8 mm）、黒白の表面2層（0.4 mm）。サポート不要。
3. 外形は200×240 mm。Bambu Studioで造形範囲に収まるよう配置し、プライムタワーやブリムを使う場合もスライス画面で確認する。
4. 白はモデル体積9.60 cm³、PLA密度1.24 g/cm³なら約11.9 g。これはパージ、プライム、ブリム等を含まない。**印刷前にBambu Studioの白フィラメント総量を確認する。**黒→白のパージを減らしすぎると白が灰色になる。
5. 校正では反射の少ないフィラメントを使い、出力後は平らな板に固定する。実際のマス間隔を複数箇所で測り、測定値を校正設定に記録する。

白をさらに節約する場合はSCADの`face_layers = 1`でSTLを再出力する。白のモデル量は約6.0 gになるが、黒い下地が透けてコントラストが下がる可能性があるため、まず小片で確認する。
