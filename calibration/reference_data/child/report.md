# 校正区間の時刻合わせ・切り出し・磁気方位検証

## 結果

姿勢変更によってカメラと子機IMUを時刻合わせし、BODY_CAPTURE_00003の開始から完了までだけを切り出した。
校正区間内のカメラIMU取付回転も独立区間で検証して採用した。
磁気方位の計算値は出力したが、磁場整合性が不足し、検証済みの絶対方位としては不採用。

## 校正動画と対応データ

[校正部分の動画](calibration_only.mp4)：1920×1080、約29.97fps、約102.39秒。
元動画の **5.396183〜107.762721秒**。対応する子機単調時刻は461.178183〜563.544721秒。
動画は元MP4から正確なシーク後にH264 CRF18で再エンコード。原本不変。動画の端はフレーム/音声サンプル単位に丸められ、数値CSVの範囲と最大1フレーム程度の差がある。
埋込テレメトリを再生成動画から解析し直さず、元動画に対応するLRFから抽出したCSVを使う。

- [IMU](imu.csv)：原本時刻・値を保持し、source_video_sとclip_time_sを追記。
- [カメラ](camera.csv)：元動画時刻・テレメトリを保持し、child_mono_sとclip_time_sを追記。
- [BNOイベント](bno_events.csv)、[HEALTH](health.csv)：同一の単調時刻範囲で抽出。
- pose_1_imu.csv〜pose_4_imu.csv：マーカーの各姿勢区間。静止性の評価では従来通り冒頭1秒・末尾0.25秒を除く。
- [磁気方位の候補値](magnetic_heading_candidates.csv)：磁北基準の候補、可観測性と不採用フラグ付き。

## 時刻・カメラ軸の校正

`child_mono_s = source_video_s + 455.782`

| 校正中の動画区間 | 最良時刻差 | 角速度ノルム相関 |
|---|---:|---:|
| 25〜48秒 | 455.774秒 | 0.951 |
| 50〜73秒 | 455.782秒 | 0.998 |
| 75〜100秒 | 455.784秒 | 0.999 |

時刻差は3区間の中央値を採用。区間差10msは整合性の指標であり、絶対同期精度ではない。
約102秒の範囲なので時計倍率は1に固定し、ドリフトを推定したとはしない。
姿勢四元数の微分によるカメラ角速度とBNO角速度を照合した。
25〜73秒で3軸回転を推定し、使っていない75〜100秒で検証：相関0.9968、RMS差0.0629rad/s。
校正値は `calibration/20261029_child_axis_003_camera_imu.json`。
機体軸への合成は `R_body_from_camera_imu = R_body_from_bno @ R_camera_imu_from_bno.T`。
これはカメラ内IMUの座標であり、光学座標・レンズ内部標定・並進の校正ではない。
時刻差は今回のクリップ専用。本番動画へ転用しない。

前回は校正完了後の110〜138秒も評価していたため全区間を不採用にした。
今回は先にマーカーを対応させ、校正中だけで推定・検証した。区間外の不一致を解消したとは主張しない。

## 磁気方位：現データでは採用不可

ユーザー指定により磁気データで北基準を検証した。
BNOの記録はGame Rotation Vectorであり、この四元数単独は磁北を含まない。
磁気ベクトルを同じ時刻のsensor→world回転で傾斜補正し、機体前方の水平射影との角度から磁気方位候補を計算した。
前方がほぼ鉛直な姿勢ではheading自体をNaNとした。

| 姿勢 | 磁場ノルム平均 | ゲーム世界に戻した磁場の水平方位 |
|---|---:|---:|
| 1 | 48.57µT | 116.31° |
| 2 | 53.27µT | 172.99° |
| 3 | 57.54µT | 100.03° |
| 4 | 56.54µT | 125.33° |

上表の角度は機体の絶対方位ではなく、「姿勢を戻した後も北の基準が安定しているか」を見る量。
最大約73°の差があるため、そのまま磁北と認定できない。

追加の一定オフセットモデル `m_sensor = bias + R_sensor_world * fixed_field` を姿勢1〜3で推定。
推定biasは約[1.325, -2.199, 6.376]µT。推定に使わない姿勢4で検証したところ、
磁場ベクトルの相対残差10.95%（基準5%）、水平方位差19.11°（基準5°）で不合格。
この補正は試行値としてmanifestにだけ保持し、採用した校正値や候補CSVへ黙って適用していない。
4姿勢だけに合う高自由度の補正で無理に北を作らない。

`absolute_heading_valid=false`、`true_heading_deg`は空欄。
磁北と真北は別であり、磁気の整合性が成立していない段階で偏角だけを加えて真北方位とはしない。
今後は本番の電装・ライト稼働状態で、周囲の磁性体を避けた全方向の磁気校正と独立した姿勢での検証が必要。
センサの保存成功履歴だけでは、その場の磁場の均一性や真北方位を保証しない。

メーカー資料：[BNO08X Data Sheet](https://www.ceva-ip.com/wp-content/uploads/2019/10/BNO080_085-Datasheet.pdf)、
[Sensor Calibration Procedure](https://www.ceva-ip.com/wp-content/uploads/2019/09/BNO080-BNO085-Sesnor-Calibration-Procedure.pdf)。

## 再現

`python scripts/clip_child_calibration.py --experiment 20261029_child_axis_003 --firmware-root ../firmware-experiments`

入力/config/コード/校正のSHA256、区間、ffmpegコマンド、採否、検証残差はmanifest.json。
元動画ハッシュ・切り出し条件・出力ハッシュが同じ場合だけ動画を再利用する。

最終検証：自動テスト170件成功、全体Lint成功。動画の1920×1080・102.388秒をffprobeで確認し、15秒地点の代表フレームで復号・画面を確認。全CSVのclip_time_sがマーカー内に収まること、原本SHA256と動画SHA256の再一致、絶対方位不採用フラグを検証。エンコードPID43956は終了し、作業用常駐プロセスなし。
