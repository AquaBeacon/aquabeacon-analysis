## フレーム選択と推定

0.5秒間隔で画像を読み、MP4は半解像度、`.LRF`は原解像度でOpenCV
`findChessboardCornersSB` を使って4×5交点を検出した。前半については後半22枚の暫定モデルで
各フレームの姿勢を求め、ボード領域のLaplacian分散180以上、
再投影RMS 0.5 px以下の13枚（0.5、2.5、3.0、4.0、4.5、5.0、5.5、6.0、6.5、
10.0、10.5、11.5、14.5秒）を採用した。9.5秒は交点の誤検出、
13.0・16.5・20.5秒などはブレや残差が大きいため除外した。
前半と後半を合わせ、`.LRF`は35枚、MP4は6.5秒で交点を検出できなかったため34枚を使用した。
前半の良好な画像はボード面の傾きが概ね35〜50°で、後半の約8〜23°を補う。
3、9、15、23、27、31秒の縮小画像も目視確認し、一部ではボード外周が画面端で切れることを確認した。

40 mm間隔の平面格子、OpenCVのピンホールモデルと放射・接線歪みモデルを使用し、`k3` を0に固定した。
推定値は1920×1080画像座標で以下の通り。

| 項目 | 暫定値 |
|---|---:|
| `fx` / `fy` | 1007.22 / 1008.22 px |
| `cx` / `cy` | 970.43 / 540.65 px |
| `k1` / `k2` | 0.3646 / 0.3438 |
| `p1` / `p2` | -0.0061 / 0.0025 |
| 再投影RMS | 0.378 px |
| 1枚ごとのRMS中央値 / 最大 | 0.354 / 0.594 px |

`.LRF` proxy画像も直接校正した。1280×720画像座標で
`fx=671.49, fy=672.27, cx=646.17, cy=360.68 px`、
`k1=0.3630, k2=0.3505, p1=-0.0059, p2=0.0019, k3=0`、
再投影RMSは0.238 px。MP4の内部行列を2/3倍した焦点距離との差は約0.02%。
6時刻でMP4と`.LRF`の交点を比較すると、交点座標の1.5倍変換後の
フレーム内位置差のばらつきは最大0.32 px（1920×1080換算）だった。
平均位置には撮影フレーム時刻の小差による移動が残る。

後半22枚のみでは`.LRF`の交互11枚ずつの推定で `fx=669.19 px` と
`645.68 px` の差があった。前半の良好な画像を加えた35枚では、交互に分けた推定値は
`fx=670.70 px` と `672.12 px`（差約0.2%）になった。
さらに時間帯ごとに0〜3秒、4〜6.5秒、10〜14.5秒、22〜27秒、27.5〜32.5秒を
それぞれ除外して再推定しても `fx=670.74〜672.17 px` に収まった。
この安定性確認は同じ動画内での検証であり、独立撮影による外部検証ではない。

## 誤差を減らす次の撮影

現状の再投影RMSは小さい。前半を追加すると0.230→0.238 pxとわずかに上がるが、
焦点距離の分割推定差は約3.5%→約0.2%へ下がる。校正ではRMSを最小化するだけでなく、
異なるフレーム群や別撮影で内部パラメータが安定するかを重視する。

1. チェッカーボードを剛性のある平板へ固定し、反りとマス間隔を測る。
2. カメラ・防水容器・FOV・Dewarp・EISを本番撮影と揃え、ボード全体を画面内に収める。
3. ボードを中央だけでなく上下左右の端にも置き、正面・傾斜・回転、近距離・遠距離を撮る。
   今回不足した画面端と姿勢の組合せを補う。
4. ゆっくり動かし、各姿勢で一瞬止める。反射、泡、ブレのあるフレームを除外する。
5. 独立した2本目の水中動画で検証し、未使用フレームの再投影残差と
   `fx, fy, cx, cy`・歪み係数の再現性を確認する。

## 適用条件と次の確認

この値は親機・子機共通の**暫定候補**。この撮影のMP4と`.LRF`は同じ画角と
交点比較で確認したため、1280×720用には上記の直接推定値を用いる。
MP4から単純縮小した場合の値 `fx=671.48, fy=672.14, cx=646.95, cy=360.43 px`
も比較用に校正JSONへ残した。既存2026-09-22動画はこのworkspaceにないため
同一画角を直接照合できず、既存解析の角度・SLAM結果の再計算はまだ行っていない。
ボード平面性も未検証。

ピンホール＋歪みモデルは防水容器を通した水中の有効モデルであり、水中の屈折を物理的に
分離して推定したものではない。再投影RMSはチェッカーボード交点へのフィットであり、
方位角や3次元位置のGround Truth誤差ではない。
