# 親子機の姿勢・位置再推定（2026-09-22、022/023/024）

2026-09-25に `data/processed/` のIMU時系列を用いて姿勢推定を再実行した。
水中カメラ校正候補の1280×720 proxy直接推定値を、既存の親機カメラによる
子機ライト追跡座標に歪み補正して適用した。旧90°仮画角の結果は変更せず、
各実験の `results/<experiment_id>/calibrated_estimate/` に別保存した。
各フォルダの `report.md` からCSV、位置グラフ、親子機の姿勢3D表示を開ける。
Blenderの再生可能なシーンと静止画も同フォルダに保存した。子機姿勢の初期水平向きは
親機と独立しており、Blender表示では任意に合わせる。Blenderは評価計算に使わない。

子機BNO085の磁気観測は022/023/024にそれぞれ3,992/4,506/3,376点ある。
保存されたQuaternionはGame Rotation Vectorで、磁気観測を方位には取り込んでいない。
磁気強度の5〜95パーセンタイルは022で13.3〜38.4 µT、023で19.8〜51.1 µT、
024で36.6〜43.0 µTだった。Game Rotation Vector基準へ回した水平磁場方向の
集中度は順に0.489、0.979、0.998。これは磁気の乱れと磁気非依存姿勢のyaw漂移の
両方を含む診断値で、コンパス精度ではない。特に022の変動が大きく、
親機方位基準と磁気・取付校正も未確認のため、磁気を使った親子機yaw合わせは適用していない。

ライト角は `cv2.undistortPoints` の正規化視線を使い、親機の融合IMU姿勢で
局所重力基準へ回した。親機位置はSONY GPSの局所ENU水平観測を参照する。
子機位置は、親機カメラ光学中心から子機ライトへのToF・視線相対位置と、
圧力深度を鉛直主観測としたIRLS融合位置を出力した。後者には子機IMUの
鉛直加速度を時間方向の拘束として使用する。光学・ToFと圧力の鉛直差中央値は
022で1.83 m、023で2.38 m、024で2.02 m。0.20 mの仮の音響端点差を許しても
深度がToF距離を超える点は順に61、129、81点あり、不整合フラグを保持した。

親機・子機の融合Quaternion、親機GPS水平位置は各実験の `localization/`、
校正後角度は `calibrated_estimate/attitude_corrected_light_angles.csv`、
ToF視線相対位置は `calibrated_estimate/parent_child_position.csv`、
圧力優先位置は `calibrated_estimate/fused_position.csv` を参照。
manifestには入力SHA-256、校正状態、取付仮定、Git SHAを記録した。

## 解釈上の制約

- 内部校正は別日撮影の暫定候補。2026-09-22映像と画角・歪みの一致を独立画像で未確認。
- 光学軸→親機IMU軸の回転は仮定。姿勢は重力基準の局所向きで、絶対方位ではない。
- 実験機体モデルにはカメラ取付面と内装の設計配置があるが、各IMU、光学中心、GPSアンテナ、子機ライト、圧力・音響センサのbody frame内中心は未測定。レバーアーム補正を適用しておらず、出力はbody原点位置ではない。
- GPSとの水平軸対応は仮のyaw 0表示。子機の絶対ENU位置とGround Truth精度は得られていない。
- 圧力とToF・ライトの幾何不整合は解消していない。融合位置は採用した圧力優先条件に依存する。

検証: `python -m pytest -q` で68件通過、`python -m ruff check .` も通過。
3実験で入力動画サイズ、角度・ToF一致・融合有効点数、各manifestを確認した。
ToF時刻差は最大0.738秒で許容値0.75秒以内、相対カメラ座標の距離ノルムと
ToF距離の差は丸め誤差1 µm以内だった。`fused_comparison.png` を3実験とも
目視確認し、圧力に沿う鉛直位置と、欠測による軌跡の分断を確認した。
各実験の`report.md`から参照するローカルファイルが全て存在することも確認した。
Blender 5.2で3実験の`.blend`と静止画を生成し、各静止画で親機proxy、
子機proxy、相対軌跡、距離線、軸を目視確認した。シーンmanifestの入力SHA-256が
再生成後のCSV・姿勢・校正ファイルと一致することを確認した。
磁気診断図も3実験で生成し、022の大きな磁場変動、023の強度変動、
024の比較的安定した方向を目視確認した。

`python -m aquabeacon_analysis localize-imu --session 20260922_cmain_022 --session 20260922_cmain_023 --session 20260922_cmain_024`
および `python scripts/estimate_calibrated_positions.py`。
