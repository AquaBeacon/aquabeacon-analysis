# C_MAIN・P_MAIN ToF距離と圧力換算水深の比較レポート

**対象実験:** 20260922_cmain_022、023、024  
**解析日:** 2026-09-23  
**解析対象:** C_MAIN 022・023・024のHEALTH_RANGEとP_MAIN 024のHEALTH_RANGE

## 要旨

C_MAINの音響ToFから親子機間の距離を求め、同じログの圧力から換算した子機水深と比較した。
音速には各行の `temp_c`、仮定した海水塩分35‰、圧力換算深度を入力する
Medwin (1975) の式を用いた。音速は約1544～1546 m/sとなり、固定1500 m/sを使った
前回の換算よりToF距離の中央値は3.7～5.6 cm長くなった。

P_MAINのToFも調査した。C_MAIN 022には同時期のP_MAIN 024ログが対応し、
送信番号 `shot_seq` とUTC時刻で154組を対応付けられた。両方のToFが有効な113組では、
P_MAINの補正距離はC_MAINより中央値で0.012 m短い。C_MAIN 023・024に対応する
P_MAINログは今回のprocessedデータに存在しない。

有効ToFと水深の相関係数は022で0.82、023で0.52、024で0.46だった。
補正後も同時刻の「ToF距離 − 圧力換算水深」の中央値はそれぞれ
−0.297 m、−0.364 m、−0.316 mである。ただしToFは親子機間の**斜距離**、
圧力換算値は水面からの**深度**で、直接の真値比較や精度評価にはならない。

## 1. データと方法

各実験の `tof_window` に含まれるHEALTH_RANGE行を使用した。両値は同じ行に記録されているため、
追加の時刻補間は行っていない。ToF距離の集計には既存の `tof_valid=1`
（`tof_us > 0` かつ `range_state ∈ {2,3}`）のみを用いた。圧力深度の時系列図には全行を表示した。
P_MAINの独立ログは、C_MAINとの `shot_seq` 一致とUTC差1秒以内の両条件で対応付けた。
ファイル番号は機器ごとに異なるため、番号の一致を対応条件には使っていない。
P_MAINの `temp_c` と `pressure_mbar` はNaNなので、同一shotのC_MAIN側の温度と深度で
P_MAINのToFも換算した。両機の比較には両方の `tof_valid=1` を要求した。

音速と距離の計算は次のとおり。

```text
c = 1449.2 + 4.6T − 0.055T² + 0.00029T³
    + (1.34 − 0.010T)(S − 35) + 0.016z
r = c × tof_us × 10⁻⁶
z = (pressure_mbar − 1013.25) × 100 / (1025 × 9.80665)
```

`T` はログの `temp_c` [°C]、`S` は仮定した塩分35‰、`z` は圧力換算深度 [m]、
`c` は音速 [m/s]、`r` はToF換算距離 [m]。`tof_us` は片道伝搬時間と仮定した。
水面気圧1013.25 mbar、海水密度1025 kg/m³も測定値ではなく仮定である。
式の出典と適用範囲は[音速補正資料](../tof_sound_speed.md)に記載した。

## 3. 解釈と制約

海水の音速補正は固定1500 m/sよりToF距離を約3%長くしたが、両系列の差は解消しなかった。
主な未確定条件は、親機の水面からの深度と水平距離、水面気圧、実測塩分、
`temp_c` が周囲水温を表すかどうか、送受信機器の固定遅延である。
子機位置の温度を音路全体の代表値とした近似も含む。
P_MAINとC_MAINのToF差は、両側の固定遅延やタイムスタンプの意味が未校正のままでは
どちらか一方の測距誤差を表さない。

したがって表の差を「ToFの誤差」や「水深の誤差」とは呼ばない。
今回の相関は両系列の変動関係を示す記述統計であり、測位の絶対精度を示さない。
特に023・024の単発値については、音響受信や判定状態を元ログと照合する必要がある。

## 4. 次の確認項目

1. 現地の塩分と水面気圧を測定値で置き換える。
2. `temp_c` のセンサ設置位置と水温への追従性を確認する。
3. 親機の深度、親子機間の水平距離、送受信機の固定遅延を記録・校正する。
4. 023の34.13秒、024の97.56秒のToF単発値について元の受信状態を確認する。
5. 023・024の時間帯にP_MAINの生ログが別途存在するか確認する。
