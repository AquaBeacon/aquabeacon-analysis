## 最初に行うこと

```powershell
git clone https://github.com/AquaBeacon/aquabeacon-analysis.git
cd aquabeacon-analysis
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[analysis,media,vision,mapping,nanyo,replay,dev]"
```

旧PCの `data/processed/` を、新PCのこのリポジトリの `data/processed/` へ同じ構造でコピーする。
移行確認が通るまで旧PCのデータを残す。動画もCSVも改名しない。

```powershell
.venv\Scripts\python scripts/verify_nanyo_handoff.py --experiment 20261101_nanyo_000 --verify-csv
```

この確認はraw/interimや旧PCの絶対パスを必要としない。転送したファイルの存在・サイズ、
155個の区間CSVの行数・UTC境界・区間秒を確認する。サイズ確認は暗号学的ハッシュ検証ではない。
day1も移した場合は `--experiment 20261031_nanyo_000` で確認できる。

### Float設定PPKを用いた静止絶対位置の追加比較

入口は`results/20261101_nanyo_000/stationary_gnss_comparison/report.html`。
Day1にも日別まとめ、各静止trialにも`stationary_gnss_comparison/<window>/`を追加した。
6窓385shotを共通に使用し、通常PPK／Float設定PPKと3種類の姿勢条件を比較する。
各区間は開始時刻から60秒。以下は姿勢補正あり・通常PPKとFloat設定PPKの共通shotでの比較。

| 日・開始JST | 平均深度 m | 共通shot | 通常PPK 3D RMSE m | Float設定PPK 3D RMSE m |
|---|---:|---:|---:|---:|
| Day1 14:41:10（探索選定） | 6.38 | 83 | 0.1985 | 0.1985 |
| Day1 15:03 | 4.78 | 170 | 0.2213 | 0.1763 |
| Day2 09:56 | 14.66 | 30 | 0.5658 | 0.2833 |
| Day2 10:15 | 16.44 | 32 | 0.2031 | 0.0865 |
| Day2 10:20（手動揺動） | 16.46 | 18 | 0.3674 | 0.3157 |
| Day2 10:32 | 6.54 | 52 | 0.4830 | 0.4830 |

これは子機絶対位置の平均周りのばらつき。従来の親子相対位置RMSEとは異なり、GNSSとの共分散を含む。
10:15の従来の相対位置RMSEは0.1397 m。これを0.0865 mへ置き換えて相対位置の改善と説明しない。
同区間の絶対位置・親機姿勢固定では通常PPK 1.3116 m、Float設定PPK 1.3604 mであり、Floatが常に小さいわけではない。
深度は水圧から求めた子機の60秒平均で、海底深度ではない。10:15の最初の約14秒は測距前の欠測。
GNSS時刻合わせは有効な隣接観測の間隔1.5秒以下のみで、位置平滑化・外挿・長い欠測補間は行わない。
同じ静止窓で方式を選定しているため、独立データによる性能検証とは扱わない。
旧位置・マッピングは維持している。数値・図の検証は同フォルダの`verification.json`。
再生成は`compare_nanyo_static_gnss.py`と`verify_nanyo_static_gnss.py`へ`--experiment 20261101_nanyo_000`を明示する。
