# 3 解析方法と評価指標

## 3.1 位置推定の流れ

親機画像で子機ライトを同定し、内部校正を使って画素から視線方向を得る。音響距離は送受信の時刻差と設定音速から求める。視線と距離を親機姿勢で世界座標へ回し、GNSSによる親機位置を加えることで、子機の絶対位置候補を得る。南予ではCAD由来のカメラ・ライト・音響・GNSSの基準点間のずれも名目値として扱う。取付位置のユーザー確認はあるが、各測定中心の独立校正ではない。

南予の静止解析は、この幾何から得た観測位置を評価する。マッピング表示で使う連続航法はさらに、GNSS・Doppler速度・親機IMU、光源方向・測距・圧力・子機IMUを融合する別の処理である。静止解析の未平滑化RMSを、融合済み航法の性能と表現しない。SfMのカメラ位置はセンサー航法の入力に戻していない。[南予航法の方法](../../20261031_nanyo_000/navigation_replay/report.md)／[現行マッピング](../../20261102_nanyo_combined_000/mapping_replay/report.md)

## 3.2 時計の対応

共通時刻はUTC秒で、表示はJSTで統一する。カメラ内姿勢から求めた角速度と機体ジャイロを複数窓で照合し、`UTC = 開始UTC + time_scale × 動画PTS秒`の対応を推定する。再起動や別の動画セッションをまたいで同じ時計係数を使わない。

プールの親・子のドリフトはそれぞれ約−24.86、−20.63 ppmで、採用窓間の最大残差は2.65、0.49 msだった。Day2は7動画を個別同期し、RMS残差1.34〜6.33 ms、最大残差2.42〜30.09 msだった。これは照合に使ったログ内の整合性で、外部時刻真値に対する保証ではない。検証範囲外の外挿フラグを保持する。[プール同期](../../20261028_ngt_000/synchronization/manifest.json)／[南予Day2同期](../../20261101_nanyo_000/synchronization/report.md)

動画のコンテナ作成日時、ファイル更新日時、親子それぞれの単調時計を、計測UTCの代わりに用いない。追加SfMは転送済みMP4で復号した実PTSをsidecarの区分線形時計に通し、要求した抽出時刻との差と外挿状態を各画像へ記録した。

## 3.3 校正と座標系

共通水中内部校正は沖縄で取得した暫定値で、対象条件はDJI Osmo Action 6、Standard（Dewarp）、EIS Off、純正防水ケース、水中である。親機というファイル名でも、両機に使うという保存済み指定に従う。MP4用とLRF用の行列を使い分け、解像度と表示回転を記録する。視点多様性や本番撮影条件の独立確認には制限がある。[共通校正の指定](../../../calibration/camera_defaults.json)

プールの親機90°、子機180°という表示回転は、画素と内部行列・歪み・光学軸の対応として修正した。南予動画へこの角度を固定的に転用しない。子機の機体軸はFRD（前・右・下）、位置表示はENU（東・北・上）である。プール修正版は磁北とGNSS真北を偏角0の仮定で重ねた結果を含む。南予は保存された真北ENU変換を使っている。両者の方位精度が同一だとは仮定しない。

圧力深度は水面圧代理値と仮定密度から計算する。プールは密度997 kg/m³、南予は1025 kg/m³を用いている。静止表の平均深度は各60秒の未平滑化の有限圧力値の平均であり、海底水深、音響斜距離、校正済みの絶対深度とは異なる。

## 3.4 数値の定義

3次元の平均周りRMSは、`R = sqrt((1/N) Σ ||p_i − mean(p)||²)`とする。分母はNで、線形トレンドは引かない。水平RMSは東・北だけを使う。一定の位置バイアスはこの指標から消えるため、Rが小さくても絶対位置が正しいとは限らない。

| 指標 | 何を数えるか | 説明できないこと |
|---|---|---|
| 音響候補率 | 全測距記録中のstate=3かつ正値 | 直接波の正答率・位置成立率 |
| 光源追跡の採用率 | 10 Hz画像のうち追跡が有効な枚数 | 独立した画素真値に対する精度 |
| 静止採用shot率 | その窓の測距記録に対する採用shot数 | 欠測を含む60秒全体の位置精度 |
| 航法有効率 | 20 Hz出力で位置が有効な時刻の割合 | 独立観測の更新率・絶対精度 |
| SfM画像登録率 | 入力画像のうち局所モデルに登録した枚数 | 静的地形の正しさ・実寸地図の完全性 |
| 再投影残差 | 復元点を画像へ投影した残差px | 地図の寸法誤差m |
| 位置合わせ残差 | 同じ航法観測への地図の一致度 | 独立な地図精度 |

南予の姿勢補正比較は同じ採用shot、同じ測距・画素・子機姿勢を使い、親機回転だけを区間平均へ固定する。比較対象は「親機姿勢を固定した仮想条件」であり、IMUを完全に外した別装置の実験ではない。

## 3.5 欠測と選択の扱い

10 Hz画像から音響shotごとに75 ms以内の最近傍を対応させ、shotを重複計上しない。喪失中の予測座標や目視点間の補間を観測位置に加えない。親機航法の慣性補完は最大5秒、子機は最大3秒で、それ以降は位置を欠測とする。地図配置の監査にはさらに、最後の観測から1秒以内で、0.15秒以下の有効な隣接航法点に挟まれる画像時刻を使った。

GNSS比較は通常PPKとFloat設定PPKの両方が有効な同じshotを用い、有効な隣接GNSS間隔1.5秒以下でのみ時刻合わせする。静止窓でGNSS方式を選んで同じ窓で評価しているため、独立試験による優位性の検証とは扱わない。

移動・揺動・遮蔽が大きい場面ほど欠測が増える可能性がある。採用された点のRMSと、採用率・最長空白・先頭欠測時間をセットで示すことが必要である。

追加の位置フォールバックは従来位置を優先し、光学＋IMU＋深度、音響L＋IMU＋深度の順に使う。後者には最大3秒の独立光学方位履歴を要する。音響・深度だけの瞬時観測で水平方位は一意に定まらない。深度の有効オフセットは過去の独立同時観測3イベント以上から求め、最大60秒だけ利用する。元の測距・光源欠測フラグは保ち、追加の推定方法を別列で記録する。新しい位置の評価は第4.5・5.6節、既存地図の評価は従来航法runのままである。
